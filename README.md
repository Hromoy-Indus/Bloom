# BLOOM

**Звук пробуждает цвет.** BLOOM — авторский интерактивный музыкальный веб-инструмент для атмосферного исполнения. Интерфейс сочетает акварельную архитектуру, SVG-элементы и визуальную реакцию на музыку. Учебный проект для промежуточного просмотра в НИУ ВШЭ; визуальный ориентир — эстетика GRIS.

## Инструменты

- **ATMOSPHERE** — протяжные синтезированные гармонии с фильтром, хорусом и реверберацией.
- **MELODY** — ручная игра, автоматическая мелодия, совместный режим и арпеджиатор. Доступны три мелодические основы, четыре паттерна, минорная и пентатоническая гаммы.
- **TEXTURE** — шумовые и тональные акценты: «Воздух», «Пыль», «Мерцание».
- **VOICE** — вокальные WAV-сэмплы: ручные ноты, автоматические аккордовые фразы и отдельная запись 8580 в режиме «Атмосфера».

Для инструментов предусмотрены независимые громкости и настройки звучания. Общие элементы управления — гармония, темп, общая громкость, воспроизведение, остановка и плавное затухание.

## Локальный запуск

Приложение не требует сборки. Нужен локальный HTTP-сервер, например Python 3:

```sh
cd ~/Desktop/BLOOM
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [BLOOM в браузере](http://127.0.0.1:8000/). Чтобы остановить сервер, нажмите Ctrl+C. Если порт занят, используйте другой порт, например 8001, и соответствующий адрес.

Также можно открыть папку проекта в VS Code и запустить `index.html` через Live Server. Открытие через `file://` может мешать загрузке вокальных сэмплов.

## Как играть

1. Включите нужные инструменты и нажмите «Воспроизвести». Изначально все инструменты выключены.
2. MELODY начинает в режиме «Вручную»: используйте экранные ноты или клавиши A S D F G H J. Для самостоятельного звучания выберите «Автоматически» или «Арпеджиатор».
3. Откройте настройки VOICE для выбора его режима и сэмпла. В режиме «Ноты» удерживайте вокальные кнопки либо переключите компьютерную клавиатуру на VOICE.
4. Меняйте параметры во время исполнения; завершите его кнопкой «Остановить» или «Плавное затухание».

Звук запускается после пользовательского действия. При скрытии страницы приложение останавливает воспроизведение.

## Технологии

HTML5, CSS3, JavaScript, SVG и [Tone.js](https://tonejs.github.io/). Используется закреплённая версия **14.8.49**, подключённая через CDN jsDelivr; для её загрузки требуется интернет. ATMOSPHERE, MELODY и TEXTURE используют синтез, VOICE — локальные WAV-файлы. React, сборщики и дополнительные UI-библиотеки не используются.

Основные файлы: `index.html`, `style.css`, четыре скрипта в `js/`, иллюстрация в `assets/images/` и четыре сэмпла в `assets/audio/`.
